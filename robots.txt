# =====================================================================
# MONT BARBIER — robots.txt
#
# Objectif : décourager les robots d'IA / aspirateurs de contenu connus
# de récupérer ce site, TOUT EN GARDANT le site normalement indexable
# par les moteurs de recherche classiques (Google, Bing...) pour que les
# clients puissent trouver le salon.
#
# ⚠️ LIMITE IMPORTANTE À COMPRENDRE :
# robots.txt est une simple DEMANDE, pas une protection technique.
# Il ne fonctionne que parce que les robots "respectueux" (les grandes
# entreprises citées ci-dessous, en général) choisissent de le lire et
# de le respecter. Un robot malveillant, un script fait maison, ou
# n'importe qui utilisant simplement son navigateur peut totalement
# ignorer ce fichier et lire/copier le contenu du site quand même,
# car le code d'un site web est de toute façon visible publiquement
# (clic droit → "voir le code source"). Ce fichier réduit la collecte
# par les robots connus et coopératifs, il ne rend rien "privé" ou
# "protégé" au sens sécurité.
#
# Cette liste n'est pas exhaustive : de nouveaux robots d'IA apparaissent
# régulièrement. Elle couvre les principaux robots connus au moment de
# la rédaction (2026).
# =====================================================================
